# Extra experiments

* `capstone_multi_phase_notebooks/`: the early capstone notebooks that cover phases 1 to 4 in one file.
* `bilstm_all_phases/`: the single notebook that fine-tunes the Phase 1 BiLSTM once per phase, with the results of its first run (Phase 4: chance-level AUC 0.51; Phase 5: macro-F1 0.1145; Phase 6: BERTScore F1 0.8036 on 150 validation documents; Phases 2, 3 and 7 failed in that run and were fixed afterwards).
